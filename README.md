# Personal portfolio

Static, responsive portfolio built with semantic HTML, CSS, vanilla JavaScript, and Pico.css.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build`.

## Personalize before publishing

- Replace the sample biography/copy in `index.html` with your own details.
- Replace `assets/sadhana-profile.jpg` with your preferred profile photo if needed.
- Replace the example skills and proficiency values with your own.
- Replace the three sample project cards, descriptions, dates, and technology labels.
- Keep the direct contact link and `recipient` in `js/main.js` set to the same email address.
- Review all content and links for accuracy.

The contact form validates in the browser and opens a mail app using `mailto:`. This site does not send or store submissions.
